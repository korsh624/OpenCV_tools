Это инструменты для работы с изображениями в Opencv Python. 
Они созданы для того, что бы помочь вам решать задачи АТС НТО
drawrectangle.py - инструмент для рисования прямоугольников на изображении. Получаем координаты и срез картинки
hsvsettingforvideo.py - программа подбора HSV маски, для последующего поиска контуров
road_threshold.py - программа подбора порога бинаризации при работе с дорожной разметкой
videoToFHoto.py - программа для разбиения видеофрагмента на кадры с заданным FPS
